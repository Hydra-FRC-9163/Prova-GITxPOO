# 📃  Prova GITxPOO

Pequenos gafanhotos,

1. Esta atividade avaliará o progresso de vocês com os dois cursos fornecidos.
2. A prova será composta por:
   - 9 questões teóricas
   - 3 questões práticas
3. Insira seu nome completo (item obrigatório).
4. A atividade avaliativa terá duração de 2 horas e 30 minutos para execução e envio, sendo permitida a saída definitiva em qualquer horário, mas com a prova completa.
5. A saída para o banheiro será permitida apenas após 30 minutos do início da prova.

---

# Primeiramente, informe seu nome

Coloque o seu nome completo no arquivo:

```java
SeuNome.java
```

---

# Como responder às questões?

## Questões Práticas

Para responder às questões práticas, acesse a pasta:

```txt
Questoes_praticas
```

Crie um arquivo `.java` para cada questão, contendo a solução solicitada.

Após finalizar:

- Salve as alterações
- Realize o commit no repositório

---

## Questões Lógicas e Teóricas

Nas questões lógicas e teóricas, basta editar o próprio arquivo da questão:

- Marcando um `X` na alternativa correta
- Ou respondendo no espaço indicado
